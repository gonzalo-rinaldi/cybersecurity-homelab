# Cybersecurity Homelab

Laboratorio personal para practicar hacking ético y desarrollar conocimientos de ciberseguridad defensiva.

## Estado

Laboratorio en desarrollo. Primera prueba documentada: conectividad ICMP desde Kali hacia Metasploitable Ubuntu, con 11 respuestas de 11 paquetes enviados y 0 % de pérdida. La IP de Kali y la verificación completa del aislamiento siguen pendientes.

## Objetivos

- Comprender la conectividad entre sistemas Windows y Linux.
- Preparar un entorno aislado para prácticas con máquinas vulnerables.
- Documentar configuraciones, decisiones y resolución de problemas.
- Incorporar monitoreo y medidas de protección durante la formación posterior.

## Alcance

Las pruebas se realizarán en sistemas propios o expresamente autorizados. Las máquinas vulnerables no deben exponerse a Internet. Las evidencias publicadas deben excluir credenciales, datos personales y secretos.
